Architecture

Data model

เพิ่ม menu_link_id บนตาราง products และ backfill ให้สินค้าปัจจุบัน มีค่าเท่ากับ id ของตัวเอง

Copy service

เพิ่ม repository function สำหรับ clone category, product, variants, modifier groups และ modifier options จากสาขาต้นทางไปสาขาปลายทาง

Catalog UI

เพิ่ม panel ในหน้า /catalog เพื่อเลือกสินค้า ปลายทาง และ policy ราคา/ซ้ำ

Copy Rules

  • สินค้าปลายทางได้ menu_link_id เดียวกับสินค้าต้นทาง
  • ถ้าปลายทางมี menu_link_id เดียวกันแล้ว default คือ skip
  • ถ้าเลือก update existing ให้ sync ชื่อ รูป สถานะ ตัวเลือก แต่คงราคาปลายทางเมื่อเลือก price policy แบบ preserve
  • category ปลายทางจับคู่ด้วยชื่อ ถ้าไม่มีก็สร้างใหม่ในสาขาปลายทาง
  • variants/modifiers เป็น record ใหม่ของสินค้าปลายทาง เพื่อให้แต่ละสาขาแก้เองได้
