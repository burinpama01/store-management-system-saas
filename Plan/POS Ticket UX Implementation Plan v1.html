POS Ticket UX Implementation Plan v1

วันที่ 2026-06-17 · Scope: StoreOS POS ticket UX parity จาก Accounting moojoom

Goal

  • ทำให้ saved ticket เป็น workflow สำหรับ cashier จริง: โต๊ะ, ลูกค้า, note, sync state, search/filter, bill history, reprint, void, QR verification และ print feedback
  • ไม่แก้ production DB โดยตรงในรอบนี้; ใช้ migration ใหม่แบบ additive สำหรับ metadata

Implementation Order

  • RED tests: เพิ่ม guard ใน pos-ticket-ui.test.ts และ pos-saved-tickets.test.ts
  • Data contract: เพิ่ม metadata fields ใน SavedOrderTicket, repository, database types และ migration 20260617000004
  • UX: ticket draft fields, search/filter, rich ticket card, bill history, reprint, void, QR verified, print status
  • Table lifecycle: เลือกโต๊ะจาก modal เข้า ticket draft และ confirm ก่อนลบตั๋วพร้อมเคลียร์โต๊ะ
  • Verification: targeted tests, POS subset, typecheck, lint, browser QA ถ้าเปิด dev server

Risks

  • Migration 20260617000004 ยังไม่ได้ apply production
  • Bill history UI ใช้ today orders; live data/RLS smoke ยังต้องรันก่อน deploy
  • Visual QA mobile/tablet/desktop ต้องตรวจหลัง dev server
