Three.js visual polish: StoreOS product stage

เปลี่ยน visual จากกล่องลอยเป็นฉาก product stage ที่สื่อระบบร้านจริง: POS terminal, ใบเสร็จ, QR ordering, shelf/stock และ analytics ribbon โดยยังเป็น decorative canvas ที่เบาและมี fallback สำหรับหน้า landing/login

Visual direction ใช้แกนกลางเป็น POS terminal มีชั้น depth และ object รอบตัว ไม่ใช่ floating box ซ้ำ ๆ
Login constraint หน้า login ต้องเบากว่า hero: ลด pixel ratio, ใช้ power preference แบบ default และคุม motion ให้นุ่ม
Fallback CSS background/glass cards ยังต้องอ่านได้ทันทีเมื่อ WebGL ใช้ไม่ได้หรือ context lost
Verification ต้องเช็ก source guard, typecheck/lint, และ browser canvas non-blank ทั้ง `/` กับ `/login`
