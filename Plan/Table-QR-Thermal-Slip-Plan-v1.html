พิมพ์ QR โต๊ะเป็นสลิปความร้อน (ผ่าน Print Hub) ตอนเปิดโต๊ะ

2026-06-30 · เดิม "เปิดโต๊ะ + พิมพ์ QR" เปิดหน้าเว็บ /table-receipt แล้วสั่งพิมพ์ผ่านเบราว์เซอร์ (A4) — ใช้กับเครื่องพิมพ์ความร้อน/บน iPad ไม่ได้

เป้าหมาย

ตอนพนักงานเปิดโต๊ะ → พิมพ์สลิป QR โต๊ะออกเครื่องพิมพ์ความร้อนอัตโนมัติผ่าน Hub (ใช้บน iPad + BT/IP ได้) — ถ้าไม่มีเครื่องพิมพ์แบบ Hub ค่อย fallback เปิดหน้า /table-receipt (เบราว์เซอร์) เหมือนเดิม

ใช้ของเดิมที่มี

ระบบ raster receipt รองรับ QR อยู่แล้ว: ReceiptLine.qrPayload → renderer วาดเป็น QR (receipt-raster-client). แค่เพิ่ม "โหมดสลิป QR โต๊ะ" ในตัวสร้างบรรทัด

ไฟล์ที่แก้/เพิ่ม

ไฟล์เปลี่ยน
printing/types.tsReceiptData: ticketMode += "table_qr"; เพิ่ม tableQrPayload?, tableValidUntil?
printing/receipt-lines.tsเพิ่ม buildTableQrLines (ชื่อร้าน + โต๊ะ + ใช้ได้ถึง + บรรทัด qrPayload + คำอธิบาย) + branch ticketMode
printing/receipt-printer-bytes.tsrequiresRaster เป็นจริงเมื่อ table_qr; ข้อความ error เป็น "QR" ทั่วไป
printing/table-qr-slip.tsใหม่ buildTableQrReceiptData(input) → ReceiptData
pos/actions.tsเพิ่ม getTableQrSlipAction(tableId) → { slip:{storeName,tableLabel,qrPayload,validUntil}, printers } (รองรับทั้ง table_bound + session_printed)
pos/TableOpenModal.tsxopen(): หลังเปิดโต๊ะ → ถ้ามี Hub printer → enqueue สลิป (เตือน Hub ออฟไลน์ด้วย); ไม่งั้นเปิด /table-receipt; เพิ่ม notice state
testsbuildReceiptLines(table_qr) มีบรรทัด qrPayload; buildTableQrReceiptData

Flow

เปิดโต๊ะ → openTableAction (สร้าง session) → getTableQrSlipAction → เลือก Hub printer → enqueueReceiptPrintJob(raster QR) → Hub agent พิมพ์ความร้อน
fallback: ไม่มี Hub printer → window.open('/table-receipt')

ตรวจสอบ

typecheck+eslint สะอาด · unit test render QR line · full suite ไม่ regress · verify ได้ผ่าน DB queue (job kind + payload) — พิมพ์จริงผ่าน agent ที่ทำงานแล้ว
