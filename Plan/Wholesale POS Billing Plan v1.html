แผนงาน: POS ขายส่ง — ออกบิล + หลายหน่วย + ราคาหลายระดับ (v1)

วันที่: 2026-07-03 · โปรเจค: Store management system saas (StoreOS) · ฐาน: ต่อยอด Grocery POS เดิม (/pos/grocery)

1) Scope — Use case 8 ข้อ เทียบของเดิม

ข้อความต้องการสถานะเดิมงานที่ต้องทำ
1ค้นหาสินค้า ชื่อ/รหัส/barcode + ราคา หน่วย สต๊อกมีเฉพาะยิง barcode/SKUช่องค้นหาชื่อแบบ live filter (client-side จาก products ที่โหลดแล้ว) แสดงราคา/หน่วย/สต๊อก
2คูณจำนวน + ราคาโหล/แพ็ค/ถาดคูณจำนวนมี แต่ไม่มีหน่วยแพ็คตาราง product_units (ชื่อหน่วย, ตัวคูณ, ราคาต่อ tier, barcode) + ปุ่มเลือกหน่วยตอนหยิบ + ช่องพิมพ์จำนวนตรง ๆ
3รวมยอดบิล subtotal/ส่วนลด/VAT/สุทธิ/รับเงิน/ทอนมีครบยกเว้นส่วนลดท้ายบิล (UI) และ VATช่องส่วนลดท้ายบิล (บาท/%) + VAT-included breakdown บนใบเสร็จ (ตั้งค่าได้)
4ใบเสร็จ thermal 58/80mmมีครบ (BT/USB/IP/Hub/PDF)เพิ่มบรรทัด "จำนวน x ราคาต่อหน่วย (ชื่อหน่วย)" สไตล์ห้าง + บรรทัด VAT
5ประวัติบิลย้อนหลัง ลูกค้า/วันที่/ยอดมี listOrdersHistory (POS หลัก)Modal ประวัติบิลในหน้า POS ขายส่ง + กรองวันที่ + พิมพ์ใบเสร็จซ้ำ
6ราคาปลีก/ส่ง/ตัวแทน/ลูกค้าประจำไม่มีcustomers.price_tier + ราคาต่อ tier บนสินค้า/หน่วย + เลือก tier หน้า POS (auto จากลูกค้า) + repricing ตะกร้า
7ตัดสต๊อกอัตโนมัติ + แจ้งใกล้หมดมี (variant stock + alert)แก้ RPC ให้ตัดสต๊อก = จำนวน × ตัวคูณหน่วย (ขาย 1 โหล ตัด 12 ชิ้น)
8เพิ่มสินค้าง่ายฟอร์ม catalog เต็มรูปแบบ (หลายขั้น)ปุ่ม "เพิ่มสินค้าเร็ว" ในหน้า POS: ชื่อ/บาร์โค้ด/ราคาปลีก-ส่ง/สต๊อก/หน่วยโหล-แพ็ค จบในฟอร์มเดียว + แก้หน่วยขายส่งใน catalog

2) Data model (migration 20260703000000_wholesale_pos.sql)

  • customers เพิ่ม price_tier text default 'retail' — ค่า: retail | wholesale | agent | regular (ปลีก/ส่ง/ตัวแทน/ลูกค้าประจำ)
  • products เพิ่ม unit_label (หน่วยฐาน เช่น ชิ้น/ขวด), price_wholesale, price_agent, price_regular (null = ใช้ราคาปลีก)
  • product_units ตารางใหม่: product_id, name (โหล/แพ็ค/ลัง), quantity (ตัวคูณ ≥2), price + ราคาต่อ tier, barcode (unique ต่อร้าน), sort_order, is_active + RLS อ่าน=สมาชิกร้าน เขียน=manager+
  • order_items เพิ่ม unit_id, unit_name, unit_quantity (default 1)
  • receipt_settings เพิ่ม show_vat_breakdown boolean, vat_rate numeric default 7 (VAT รวมในราคา — แสดงบนใบเสร็จเท่านั้น ไม่แตะบัญชี)
  • RPC create_pos_order_with_items: รับ unit fields + validate ราคา unit ตรงกับราคา tier ที่ตั้งไว้ / close_pos_order_payment: ตัดสต๊อก sum(quantity × unit_quantity)

หมายเหตุ: สต๊อกยังอยู่ที่ variant เหมือนเดิม — สินค้าที่ต้องตัดสต๊อกต้องมี variant (ฟอร์มเพิ่มสินค้าเร็วสร้าง variant "มาตรฐาน" ให้อัตโนมัติ)

4) กติกาความถูกต้องของราคา (trust model)

  1. Client ส่ง cart → server สร้าง trusted cart ใหม่จาก catalog + tier เสมอ (เหมือนเดิม)
  2. tier ที่ใช้: ถ้าเลือกลูกค้า → ใช้ tier ของลูกค้าจาก DB (client ปลอมไม่ได้); ถ้าไม่เลือกลูกค้า → แคชเชียร์เลือก tier ได้ (พฤติกรรมร้านขายส่งหน้าร้าน)
  3. RPC ตรวจซ้ำ: ราคาต่อหน่วยต้องตรงกับราคา tier ใดราคาหนึ่งที่ตั้งไว้ในระบบเท่านั้น
  4. ขาย 1 โหล → order_items 1 แถว (qty=จำนวนโหล, unit_quantity=12) → ตัดสต๊อก qty×12 ตอนปิดบิล
