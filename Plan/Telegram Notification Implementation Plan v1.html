Telegram Notification Implementation Plan

เพิ่ม Telegram notify สำหรับ owner โดยให้ tenant ระบุ chat ID เอง ส่วน bot token อยู่ใน .env.local และห้ามส่งแจ้งเตือนข้าม tenant

Goal

ระบบต้องส่ง Telegram ไปยัง group ของ tenant/owner ตาม organization_id และ store_id ที่ผูกกับ event เท่านั้น

Architecture

ใช้ target ระดับ tenant สำหรับ telegram_chat_id และใช้ notification_settings เดิมเป็น event toggle ระดับ store/channel

Safety

ไม่อ่านหรือ expose token จาก .env.local, ไม่ push migration ไป remote DB โดยไม่มี approval, ไม่ให้ client ส่ง chat ID เข้ามาเอง

Notification Events

  • new_pos_order: เมื่อสร้าง POS order
  • new_qr_order: เมื่อลูกค้าสั่งผ่าน QR
  • new_buffet_order: เมื่อ QR/POS order มาจาก buffet session หรือ table session ที่เป็น buffet
  • payment: เมื่อชำระเงินสำเร็จ
  • order_cancelled: เมื่อ void/cancel/refund เท่าที่ action ปัจจุบันมี
  • service_request: เรียกพนักงานหรือ request ที่ควรรู้ทันที
  • test: กดทดสอบจาก settings
