งาน

  1. เว็บ (ทุกที่): public/sounds/alert-new-order.mp3 · alert-sound.ts เพิ่ม pattern "order" ถอดรหัสไฟล์ด้วย AudioContext ที่ปลดล็อกแล้ว (โหลดล่วงหน้าตอนแตะจอครั้งแรก) ถ้ายังโหลดไม่เสร็จ/ล้ม ใช้ beep เดิมแทน (ไม่มีทางเงียบ) · QR + เดลิเวอรี + toast ของออเดอร์ใหม่ใช้ "order" · proxy matcher ยกเว้น .mp3 (ไม่ redirect ไป login)
  2. Android native: res/raw/alert_new_order.mp3 · MainActivity สร้าง notification channel storeos_orders (IMPORTANCE_HIGH, เสียงไฟล์นี้, สั่น) · versionCode 3 / versionName 1.0.2 · build APK (ลิงก์ดาวน์โหลด) + AAB (Play Console)
  3. Push: buildFcmMessage ใส่ android.notification.channel_id=storeos_orders + sound สำหรับ new_qr_order, new_buffet_order, new_delivery_order — แอปเวอร์ชันเก่า (ไม่มีช่องนี้) Android ใช้ช่องสำรองของ FCM อัตโนมัติ ไม่พัง
  4. Push เดลิเวอรี: migration ขยาย check constraint notification_settings + notification_templates เพิ่ม new_delivery_order · types/templates/หน้า settings/Notification Center · processInboundOrder เรียก notifyOwnerSafely หลังบันทึกออเดอร์ใหม่ (ไม่ยิงซ้ำตอน JDC ส่งซ้ำ) · toast ของ Notification Center ข้าม type นี้เมื่อ realtime ทำงาน (DeliveryGlobalNotifier มี dialog+เสียงอยู่แล้ว)
  5. Log: ความล้มเหลวของ push ถูก log โดย dispatcher อยู่แล้ว · การโหลดไฟล์เสียงล้ม log console (ฝั่ง client)

ลำดับ deploy

  1. apply migration ขึ้น prod ก่อน merge (ขออนุญาตก่อน)
  2. merge → Vercel deploy (เว็บได้เสียงใหม่ทันที, push มี channel_id)
  3. ติดตั้ง APK 1.0.2 ที่มือถือ / อัปโหลด AAB ขึ้น Play Console (ผู้ใช้ทำ)

ทดสอบ

  • unit: FCM message ของออเดอร์ใหม่มี channel_id/sound, ของประเภทอื่นไม่มี · pattern ของ toast เลือก "order" เฉพาะออเดอร์ · ingestion เรียกแจ้งเตือนครั้งเดียว
  • build Android ผ่าน (assembleRelease + bundleRelease) · ตรวจว่ามี res/raw/alert_new_order.mp3 ใน APK
  • ที่ร้าน/มือถือจริง (ผู้ใช้): ล็อกจอ → สั่ง QR → ได้ยินเสียงใหม่ · ออเดอร์เดลิเวอรีเข้า → ได้ยินเสียงใหม่ · เปิดแอปค้าง → เสียงวนจนกดรับ
ข้อจำกัด: Android ล็อกเสียงของช่องแจ้งเตือนไว้ตั้งแต่สร้างครั้งแรก — ถ้าต่อไปจะเปลี่ยนไฟล์เสียงต้องใช้ channel id ใหม่ · ผู้ใช้ปิดเสียง/ลดความสำคัญของช่องในตั้งค่าเครื่องได้เอง · iOS ยังไม่มีแอป
