Risk Disposition

Risk Status Mitigation ที่ทำแล้ว Next Gate
Live Supabase migrations / RLS Approval required เพิ่ม readiness report และมี script test-user ที่ dry-run/fail-closed อยู่แล้ว ผู้ใช้อนุมัติ remote target, backup/rollback, และคำสั่งที่จะรัน
Provider notification delivery Token missing readiness report บอก missing/present โดยไม่พิมพ์ค่า secret ตั้งค่า provider token ใน env ที่ถูกต้องแล้วอนุมัติ test send
Browser visual QA Manual gate กำหนด gate และ baseline command สำหรับเช็คความพร้อมก่อนเปิด dev/browser เปิด dev server, login test user, เก็บ screenshot desktop/mobile
Printer hardware support Hardware required unit coverage และ adapter fail-closed ลด risk ที่ unsupported จะ silently pass ทดสอบกับ printer รุ่นจริงหรือ lab device ก่อน claim ทุกรุ่น

Commands

npm run risk:check npm run risk:check -- --strict node scripts/create-test-user.mjs --dry-run

Decision

  • ห้ามรัน remote migration, remote test-user write, provider send หรือ printer hardware claim จนกว่าจะมี approval และ target ชัดเจน.
  • ใช้ npm run risk:check เป็น preflight ก่อน browser QA, deploy preview หรือ production readiness ทุกครั้ง.
  • ถ้า --strict ยังขึ้น STRICT_STATUS=blocked ให้ถือว่ายังมี gated risk เหลืออยู่ ไม่ให้ปิดงานเป็น production-ready.
