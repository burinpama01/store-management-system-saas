StoreOS Theme

Theme Presets + Custom

เปลี่ยน Theme presets จาก preview ให้เป็นฟีเจอร์จริงสำหรับแต่ละ store/tenant พร้อม custom color ที่บันทึกได้และไม่กระทบร้านอื่น

Goal

สิ่งที่จะได้

  • เลือกรูปแบบสีจาก preset ในหน้า /settings/store
  • เพิ่ม preset custom ให้แก้ primary/accent/soft ได้เอง
  • บันทึก theme ลง store ปัจจุบันเท่านั้น
Data

Tenant Isolation

  • เพิ่มคอลัมน์ theme ใน stores
  • update ผ่าน storeId + organizationId เดิม
  • ไม่สร้าง shared global state ที่ทำให้ข้าม tenant
Runtime

CSS Tokens

  • layout inject --tenant-primary
  • fallback เป็น Caramel Cafe default
  • dashboard/POS/settings ใช้ token เดิมต่อทันที

Implementation Steps

  1. เขียน RED tests สำหรับ preset registry, custom validation, UI wiring, runtime theme injection
  2. เพิ่ม src/modules/theme/presets.ts เป็น source of truth ของ preset และ validator
  3. เพิ่ม migration local สำหรับ theme columns ใน stores
  4. อัปเดต Store, repository, database types และ store update action
  5. เปลี่ยนหน้า settings จาก preview card เป็น selector + custom color controls
  6. inject CSS variables ใน dashboard layout ตาม store theme
  7. รัน tests/typecheck/lint/build หลัง bump version ตามกฎโปรเจกต์
  8. ส่ง code review gate และบันทึก Obsidian log

Preset Set

Custom จะใช้สีที่ผู้ใช้ระบุเอง แต่ยัง validate เป็น HEX เท่านั้น
