PR A: จองสต็อกจนครัวรับออเดอร์

สถานะ: ทำเสร็จ · branch feat/qr-stock-reservation
  • ลูกค้าสั่ง = จอง (reserved_quantity / reserved_units) · ยอดพร้อมขาย = สต็อก − จอง
  • ครัวกด รับออเดอร์ (แทน "เริ่มเตรียม") = ตัดจริง · ชำระเงินโดยครัวไม่เคยรับ = ตัดจริง
  • ลูกค้ายกเลิก / ครัวปฏิเสธรายการ / ปฏิเสธทั้งออเดอร์ ก่อนรับ = คืนยอดจอง · ปฏิเสธหลังรับ = คืนสต็อกจริง (provenance เดิม)
  • จุดเดียวที่ตัด/คืน: trigger qr_order_stock_lifecycle บน orders — ครอบทุกเส้นทาง
  • POS/Stock Pool/QR ตรวจยอดพร้อมขาย · หน้าลูกค้าขึ้น "หมด / เหลือ n" (RPC qr_menu_pool_availability ให้ anon ไม่เปิดตาราง Pool) · หน้าสต็อกโชว์ "จอง n · พร้อมขาย n"
  • ออเดอร์เก่าที่เปิดค้าง (stock_state ว่าง) ทำงานแบบเดิม 100% · Unified POS ไม่เปลี่ยน
