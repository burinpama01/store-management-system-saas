สรุปการตัดสินใจ (ยืนยันแล้ว)

ข้อ 2 GPS: บังคับจับตำแหน่งจริง เฉพาะร้านที่เปิด geofence — เปิดแล้วไม่มี location = กดเข้างานไม่ได้ (ร้านที่ไม่เปิดไม่กระทบ)
ข้อ 3 วันทำงาน: เพิ่ม ตั้งค่า "วันเปิดทำการ" ระดับร้าน (ดีฟอลต์ 7 วัน) ใช้เป็นค่าเริ่มต้นของปฏิทิน (per-employee ที่มีอยู่ยัง override ได้)
ข้อ 7 บัญชี: cashier/staff ยัง บันทึกเงินสดได้ แต่ ซ่อนการ์ดกำไร/ขาดทุน + ยอดรวม (เห็นเฉพาะ manager+)

งานรายข้อ

1ฟอร์มเปิด-ปิดตามหัวข้อ (ไม่กินพื้นที่)

ปรับ AttendanceManager.tsx ให้ส่วนของผู้จัดการ/เจ้าของเป็น ToggleSection (เปิด-ปิดได้) แบบเดียวกับ CustomerLoyaltyManager: รายการ+ฟิลเตอร์, เพิ่มเวลาย้อนหลัง, แก้ไขเวลา, วันหยุดร้าน, วันลา, ตั้งค่า GPS/วันเปิดทำการ

edit app/(dashboard)/attendance/AttendanceManager.tsx · UI ล้วน

2บังคับจับตำแหน่งจริงจึงเข้างานได้ (เมื่อเปิด GPS)

  • getAttendanceGpsPolicy: ให้ gpsEnabled = settings.geofenceEnabled (ผูกกับ "ร้านเปิด GPS" ไม่ใช่แค่ feature ของแพ็กเกจ)
  • validateAttendanceGpsPolicy: ถ้า gpsEnabled และไม่มี lat/lng → error "กรุณาอนุญาตตำแหน่งเพื่อบันทึกเวลา" (เดิมบังคับเฉพาะตอนตั้ง center); ถ้ามี center ก็ตรวจรัศมีต่อ
  • ใช้กับทั้ง clock-in และ clock-out

edit modules/attendance/policy.ts · app/(dashboard)/attendance/actions.ts

3ปฏิทิน: ทำงาน เสาร์-อาทิตย์ (วันเปิดทำการระดับร้าน)

  • migration เพิ่ม store_hr_settings.working_days int[] default {0,1,2,3,4,5,6} (เปิด 7 วัน)
  • hr/types.ts + hr/repository.ts: เพิ่ม workingDays ใน StoreHrSettings + map + upsert; database.types.ts อัปเดต
  • attendance/page.tsx: ส่ง store working_days เป็น fallback ให้ computeDayStatuses (per-employee profile ยังชนะถ้ามี) → เสาร์-อาทิตย์ที่เปิดทำการจะถูกนับ (มา/สาย/ขาด) ไม่ใช่ "off"
  • UI ตั้งค่าวันเปิดทำการ (checkbox 7 วัน) ในส่วนตั้งค่าของ AttendanceManager (สิทธิ์ settings.manage_store)

หมายเหตุ: วัน "holiday" มาจาก store_holidays เท่านั้น — ระบบไม่เคยมาร์คเสาร์-อาทิตย์เป็น holiday อยู่แล้ว ปัญหาคือมันถูกมองเป็น "off" (ไม่นับขาด) เพราะ default Mon-Fri งานนี้แก้ที่ default

4ตั้งวันหยุดโดยเจ้าของ มีอยู่แล้ว

store_holidays + addHolidayAction/deleteHolidayAction (สิทธิ์ settings.manage_store = owner/admin) มีครบแล้ว — งานนี้แค่จัดให้อยู่ใน ToggleSection ของข้อ 1 ให้ใช้ง่าย

5เจ้าของแก้ไขเวลาเข้า-ออกย้อนหลัง มีอยู่แล้ว

addManualAttendanceAction (เพิ่มย้อนหลัง) + adjustAttendanceAction (แก้เวลา) + deleteAttendanceAction (สิทธิ์ attendance.manage = manager+/owner) มีครบ — จัดเข้า ToggleSection + ยืนยันเจ้าของใช้ได้

6cashier/staff ออกงานไม่ได้ถ้ายังไม่ปิดรอบเงินสด

  • ใน clockOutAction: ถ้า role เป็น cashier/staff และ getOpenCashSession(storeId) มีรอบเปิดอยู่ → block "กรุณาปิดรอบเงินสดก่อนออกงาน"
  • cash session เป็น per-store (1 รอบ/ร้าน) — manager+ ไม่ติด gate นี้

edit app/(dashboard)/attendance/actions.ts (เรียก getOpenCashSession จาก cashflow)

7ซ่อนกำไร/ขาดทุนจากพนักงานต่ำกว่า manager

  • หน้า /accounting โชว์การ์ด "กำไร/ขาดทุน" (netCashflow) ให้ทุกคนที่มี cashflow.view (รวม cashier/staff)
  • เพิ่ม prop canViewTotals = can("reports.view") (manager+) → ซ่อนการ์ดสรุป (กำไร/ยอดรวม) สำหรับ cashier/staff; คงฟอร์มบันทึกรายรับ-จ่าย + รอบเงินสด
