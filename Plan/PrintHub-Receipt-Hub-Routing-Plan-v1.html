ทำให้ auto-print "ใบเสร็จ" ทุกจุดวิ่งผ่าน Print Hub

2026-06-30 · ปิดช่องโหว่: ปัจจุบันมีแต่ "ตั๋วครัว" ที่ผ่าน Hub; ใบเสร็จของ QR/Delivery ใช้เบราว์เซอร์ (Web Bluetooth/USB) → iPad พิมพ์ไม่ได้; POS ถ้าตั้ง printer เป็น Bluetooth ก็ไป Web Bluetooth

เป้าหมาย

ใบเสร็จ auto-print ทุกจุด (POS / QR / Delivery) ต้อง enqueue เข้า Hub ด้วย printerId เมื่อเครื่องพิมพ์หลักเป็นชนิดที่ Hub รองรับ (IP/WiFi หรือ Bluetooth-ผ่าน-Hub) — ให้ทำงานบน iPad; ถ้าไม่มีเครื่องพิมพ์แบบ Hub ค่อย fallback ไปเบราว์เซอร์ (BT/USB) เหมือนเดิม

สถานะปัจจุบัน vs หลังแก้

จุดใบเสร็จ (ก่อน)ใบเสร็จ (หลัง)
POS จ่ายเงินIP=Hub ✅ / Bluetooth=Web BT ❌IP=Hub ✅ / BT-Hub=Hub ✅ / else browser
QR ordersเบราว์เซอร์เท่านั้น ❌Hub (ถ้ามี default printer แบบ Hub) ✅ / else browser
Delivery (ตั๋วรวมบิล)เบราว์เซอร์เท่านั้น ❌Hub ✅ / else browser

หลักการเลือกเครื่องพิมพ์

selectConfiguredPrinter(printers, preferredId) → preferred ก่อน ไม่งั้น default (isDefault). ถ้าเครื่องที่เลือกเป็น isHubReceiptPrinter = ip/escpos ที่มี ipAddress หรือ bluetooth ที่มี hubBluetoothPort → enqueue เข้า Hub. ไม่งั้น → printReceiptAuto (BT/USB/PDF).

หมายเหตุ: ไม่แตะเส้น IP เดิมของ POS (printService→ipAdapter→sendNetworkPrintJob = bridge-ก่อน-แล้ว-enqueue เร็วบนเครื่องแคชเชียร์) — เพิ่มเฉพาะ BT-Hub + เปลี่ยน QR/Delivery มาใช้ router ใหม่
