Locked Business Rules

เรื่อง กฎที่ล็อกแล้ว
ตำแหน่งฟีเจอร์ขอเพลง เพิ่มเป็นแท็บใน QR Ordering เดิม ไม่ทำ route แยกใน MVP
แพ็กเกจ Music Request ใช้ได้เฉพาะ Enterprise และต้องมี license approved เท่านั้น
QR ผูกโต๊ะ ขอเพลง/ดูคิวเพลงได้แม้ไม่มี active bill/session และหลังเช็คบิลแล้วก็ยังใช้ได้
QR ไม่ผูกโต๊ะ QR สร้างตอนเปิดโต๊ะและพิมพ์ให้ลูกค้า ใช้ได้เฉพาะ session active; หลังเช็คบิลให้แสดงหน้า QR หมดอายุ
อาหาร แท็บอาหารยังต้องมี active table session เหมือนเดิมทุกโหมด
เพลงร้านเปิดเอง ไม่เข้าคิวเพลง; คิวเพลงมีเฉพาะ customer requests

Eligibility Matrix

QR mode Session state สั่งอาหาร ขอเพลง/ดูคิว ผลที่ต้องแสดง
table_bound ไม่มี active session ไม่ได้ ได้ ถ้า music gate ผ่าน แท็บอาหารขึ้นข้อความให้เปิดบิล; แท็บเพลงใช้งานได้
table_bound active session ได้ ได้ ถ้า music gate ผ่าน ใช้งานได้ทั้งสองแท็บ
session_printed active session และ query session ตรงกับ current_session_id ได้ ได้ ถ้า music gate ผ่าน ใช้งานได้ทั้งสองแท็บ
session_printed ไม่มี session, session หมดอายุ, หรือ query session ไม่ตรง ไม่ได้ ไม่ได้ หน้าเต็ม: QR หมดอายุแล้ว กรุณาขอ QR ใหม่จากพนักงาน

Data Model Proposal

Migration warning: ห้าม apply production migration โดยไม่ขอ approval แยก ต้องทำ local/preview validation ก่อน

-- supabase/migrations/YYYYMMDDHHMMSS_qr_music_request_enterprise.sql

alter table stores
  add column if not exists qr_ordering_mode text not null default 'table_bound'
    check (qr_ordering_mode in ('table_bound', 'session_printed')),
  add column if not exists music_request_enabled boolean not null default false,
  add column if not exists music_license_status text not null default 'not_requested'
    check (music_license_status in ('not_requested', 'pending', 'approved', 'rejected', 'expired')),
  add column if not exists music_license_approved_at timestamptz,
  add column if not exists music_license_note text;

create table if not exists music_requests (
  id uuid primary key default gen_random_uuid(),
  store_id uuid not null references stores(id) on delete cascade,
  table_id uuid references tables(id) on delete set null,
  table_number text,
  session_id uuid,
  requester_label text,
  song_title text not null,
  artist_name text,
  note text,
  status text not null default 'pending'
    check (status in ('pending', 'approved', 'played', 'rejected', 'skipped', 'expired')),
  requested_at timestamptz not null default now(),
  decided_at timestamptz,
  decided_by uuid references auth.users(id),
  played_at timestamptz,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create index if not exists music_requests_store_status_created_idx
  on music_requests(store_id, status, requested_at);

create table if not exists music_request_audit_logs (
  id uuid primary key default gen_random_uuid(),
  store_id uuid not null references stores(id) on delete cascade,
  music_request_id uuid references music_requests(id) on delete set null,
  actor_user_id uuid references auth.users(id),
  actor_type text not null check (actor_type in ('customer', 'staff', 'system')),
  action text not null,
  details jsonb not null default '{}'::jsonb,
  created_at timestamptz not null default now()
);

alter table music_requests enable row level security;
alter table music_request_audit_logs enable row level security;

revoke all on music_requests from public, anon, authenticated;
revoke all on music_request_audit_logs from public, anon, authenticated;

MVP ใช้ tables.current_session_id เป็น session token ใน URL สำหรับ session_printed. URL ที่พิมพ์ตอนเปิดโต๊ะคือ /qr/[storeSlug]/[tableId]?s=[current_session_id]. เมื่อปิดโต๊ะ/เช็คบิลแล้ว close_table_session จะ clear session ทำให้ QR เดิมหมดอายุ
