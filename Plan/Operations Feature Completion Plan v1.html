Operations Feature Completion Plan v1

ปิดงาน 9 ข้อที่เหลือ (#3–#11) จากรีวิว role=owner — หลายข้อมีโครง module อยู่แล้ว แต่ UI/flow ไม่ครบ จัดเป็นเฟสตามความเกี่ยวเนื่อง/ขนาดงาน

สถานะของเดิม (มีฐานแล้ว)

  • QR ordering: มีบางส่วน customer page + staff table board มีแล้ว (ขาด แจ้งเตือน/บิล/ประวัติ/เรียกพนักงาน)
  • buffet/stock/accounting/attendance: module มีแล้ว ขาด settings/flow บางหน้า
  • storage buckets product-images: มีแล้ว (พร้อมต่อ #5)

Phase A — Settings & quick wins

#3 เชื่อมต่อเครื่องพิมพ์ก่อนทดสอบ

  • เพิ่มปุ่ม "เชื่อมต่อเครื่องพิมพ์" (WebUSB/WebBluetooth/IP) ในแท็บใบเสร็จ → จับคู่อุปกรณ์ แล้วปุ่มทดสอบจึงพิมพ์จริง
  • เก็บ config printer (มี printers table) + capability fail-closed

#4 แผนที่เลือกตำแหน่ง GPS เข้างาน

  • ฝัง map (Leaflet/OSM หรือ Google Maps — GOOGLE_MAPS_API_KEY มีใน env) ในตั้งค่า GPS → คลิกปักหมุด + ลากปรับ + วงรัศมี

#9 ตั้งค่าบุฟเฟต์ + เลือกแสดงบน QR order

  • หน้าตั้งค่าแพ็กเกจบุฟเฟต์ (ราคา/เวลา/เงื่อนไข) + toggle สินค้าที่แสดงบน QR (available_for_qr มีแล้ว)

Phase B — Data & storage

#5 อัปโหลดรูป + ย่อขนาด/ลดคุณภาพอัตโนมัติ

  • อัปโหลดรูปสินค้า/เมนู → resize+compress (sharp ฝั่ง server หรือ canvas ฝั่ง client) ก่อนเก็บ Supabase Storage (bucket มีแล้ว) → โหลดเร็วขึ้น
  • ใช้ progress (มี uploadWithProgress แล้ว)

#8 สต็อกเชื่อมกับสินค้า

  • ผูก stock กับ product/variant (ตัด stock เมื่อขาย POS/QR, แจ้งเตือนของใกล้หมด — มี stock-alerts test แล้ว)

Phase C — Cash & QR operations

#7 กระแสเงินสด เปิด/ปิดร้าน

  • บันทึกเงินสดตอนเปิดร้าน (opening float) / ปิดร้าน (closing count) → cash session + กระทบยอดกับ POS payments

#6 QR Order ครบวงจร ใหญ่สุด

  • ฝั่งลูกค้า: สั่ง/เรียกพนักงาน/ดูรายการ-สถานะ-ยอด-บิล-ประวัติ
  • ฝั่งร้าน: แจ้งเตือนออร์เดอร์ใหม่ (realtime) / รายละเอียด/สถานะ/ประวัติ/ยอดชำระ/บิล

Phase D — HR / Payroll

#10 จัดการพนักงาน + แก้เวลาเข้าออก

  • เพิ่ม/ลบ/แก้พนักงาน (ต่อยอดจาก team settings) + แก้ไข/เพิ่มบันทึกเวลาเข้า-ออกย้อนหลัง

#11 บัญชีพนักงาน + เงินเดือน/รายวัน + บทลงโทษ

  • ตั้งเงินเดือน/ค่าแรงรายวันต่อคน → คำนวณจากเวลาเข้าออก (มี payroll summary แล้ว) + หักขาด/ลา/มาสาย

ข้อเสนอลำดับ

แนะนำเริ่ม Phase A (เห็นผลเร็ว, ความเสี่ยงต่ำ) → B → C → D. แต่ #6 (QR ครบวงจร) เป็นงานใหญ่สุด อาจแยกทำเป็นรอบเฉพาะ
