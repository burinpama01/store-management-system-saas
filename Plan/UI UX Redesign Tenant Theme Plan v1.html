StoreOS UI/UX Redesign Plan v1

Modern Colorful SaaS UI พร้อม Tenant Theme Customization

แผนปรับ UX/UI ใหม่ให้สด ทันสมัย อ่านง่าย ใช้งานเร็ว และให้แต่ละ tenant ตั้งค่าสีแบรนด์ของร้านได้ โดยยังคุม accessibility, role-based UI และ feature gating ตามแพ็กเกจ.

Design Direction

Visual

Colorful Professional

ใช้สี tenant เป็น brand signal แต่คุมพื้นหลังให้สว่าง อ่านง่าย และไม่ทำให้ dashboard กลายเป็น one-note palette.

UX

Operational First

POS, เมนูสินค้า, รายงาน และ settings ต้อง scan เร็ว กดซ้ำได้ง่าย ไม่ใช้ landing-style layout ในหน้าทำงาน.

Personalization

Tenant Theme Control

แต่ละ tenant เลือก preset หรือกำหนด primary/accent/success/warning ได้ พร้อม preview และ contrast validation.

UX Scope

Core screens
  • Dashboard: KPI dense, charts, quick actions, alert strip
  • Catalog: product image grid/table toggle, category rail, side drawer edit
  • POS: product image tiles, color-coded categories, receipt action zone
  • Settings: theme builder, diagnostics, package limits
States
  • loading skeleton ที่ไม่ทำ layout shift
  • empty state ที่มี action เดียวชัดเจน
  • permission/package locked state แสดงเหตุผลและ upgrade path
  • error state แยก user error กับ system error

Implementation Plan

Phaseงานไฟล์หลักVerification
1. Token Foundation เพิ่ม theme token, preset, contrast validator, CSS variable mapper src/modules/theme/*, src/app/globals.css unit test validator + token snapshot
2. Tenant Theme Storage เพิ่ม schema/migration สำหรับ tenant/store theme profile supabase/migrations/*theme*.sql, database types RLS/storage tests, no cross-tenant write
3. Theme Builder UI settings page สำหรับ preset, color swatches, live preview, reset settings/theme/*, shared controls role/package gate tests + browser screenshot
4. Core Screen Redesign dashboard, catalog, POS, reports ใช้ token ใหม่และ responsive rules dashboard, catalog, pos, reports desktop/mobile visual QA, no overlap, no contrast fail
5. Polish & Rollout migration fallback, theme import/export, audit log, QA checklist docs, Plan, tests/unit/ui-regressions.test.ts full tests, typecheck, lint, code_reviewer

Acceptance Criteria

  • แต่ละ tenant/store ตั้ง theme ได้โดยไม่กระทบ tenant อื่น
  • ทุกสีผ่าน contrast อย่างน้อย WCAG AA สำหรับ text/action หลัก
  • Free ใช้ preset ได้, package สูงขึ้นปลดล็อก custom color/logo ตามระดับ
  • POS และ catalog แสดงรูปสินค้าอย่างสวยงาม ไม่เกิด layout shift บน mobile
  • role ที่ไม่มีสิทธิ์เห็น preview ได้ แต่ save/theme management ต้องถูก disable และ server action ต้อง fail closed
  • มี visual QA screenshot desktop/mobile ก่อนสรุปว่างาน UI เสร็จ
