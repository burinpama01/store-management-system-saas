เป้าหมาย v1

Platform Control

  • เพิ่มหน้า `/system` สำหรับ `super_admin` เท่านั้น
  • จัดการ organizations, owners, subscriptions, user access
  • ดู audit/security events ที่เกี่ยวกับการเปลี่ยนสิทธิ์

Trust & Security

  • เพิ่ม real Supabase auth E2E สำหรับ invite/reset/recovery
  • ตรวจ RLS isolation ด้วย test user จริง
  • ยืนยัน Stripe webhook idempotency และ rollback path

Release Readiness

  • Vercel preview deploy พร้อม env checklist
  • browser QA สำหรับ desktop/mobile flows หลัก
  • บันทึก runbook deploy/rollback ที่รันจริงแล้ว

Definition of Done

  • `/system` เห็นเฉพาะ `super_admin` หรือ permission `system.manage`
  • ไม่มี tenant/org data leak ระหว่าง organization
  • reset/invite password flow ผ่าน real browser E2E
  • unit/typecheck/lint/full tests ผ่านหลังแก้
  • code_reviewer ผ่านทุก code/config/security change
  • Obsidian `log.md`, `current.md`, `issue-index.md` sync แล้ว
  • ไม่มี secret/token/password ใน log, test, หรือ commit
  • ก่อน build/commit ต้อง bump version ตาม AGENTS.md
