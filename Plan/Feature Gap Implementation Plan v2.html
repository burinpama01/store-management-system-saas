Package V2-A: Catalog UI Redesign

Goal: หน้าเมนูสินค้าใช้งานเร็วขึ้น ดูเป็นระบบ POS จริง และรองรับรูปสินค้า/role visibility.

Files: src/app/(dashboard)/catalog/CatalogManager.tsx, src/app/(dashboard)/catalog/page.tsx, src/app/globals.css, tests/unit/ui-regressions.test.ts

  • เพิ่ม responsive layout: desktop 3 zones, tablet 2 zones, mobile stacked tabs.
  • เปลี่ยน category sidebar ให้แสดง count, status, edit permission และ empty state.
  • เพิ่ม product cards พร้อม image preview, price, variant/modifier count, POS/QR badges, stock badge, package lock badge.
  • คง table/list mode สำหรับร้านที่มีสินค้าเยอะ พร้อม horizontal scroll ที่ mobile.
  • เพิ่ม role view indicator: แสดงว่า current user role อะไรและทำ action ใดได้/ไม่ได้.
  • ห้ามใช้ emoji เป็น icon หลัก; ใช้ text badge หรือ icon component ที่มีอยู่ใน repo ถ้ามี.

Package V2-B: Role-Based UI Separation

Goal: แต่ละ role เห็น navigation/action ชัดเจน และไม่มีปุ่มที่กดแล้วโดน server reject แบบงง.

Files: src/modules/auth/permission-resolver.ts, src/shared/components/SideNav.tsx, src/app/(dashboard)/layout.tsx, src/app/(dashboard)/**, tests/unit/permission-resolver.test.ts, tests/unit/ui-regressions.test.ts

RoleUI DefaultLocked/Hidden Examples
Ownerเห็นทุก dashboard/settings/billingไม่มี ยกเว้น super_admin-only platform tools
Adminจัดการร้าน, เมนู, POS, report, staffbilling owner action, owner removal
ManagerPOS, catalog, stock, reports, attendance managebilling, package upgrade, owner/admin permission escalation
CashierPOS, receipt, own attendancedelete bill ถ้าไม่มี permission, settings, reports advanced

  • สร้าง role UI matrix helper สำหรับ nav/action labels.
  • ทุก disabled action ต้องมี tooltip/help text สั้นว่า locked เพราะ role หรือ package.
  • ทุก server action ยังต้องใช้ requirePermission(); UI ไม่ใช่ security boundary.

Package V2-C: POS Product Images

Goal: รูปเมนูใน Catalog ไปแสดงใน POS และ QR ordering โดยไม่ทำให้ layout กระโดด.

Files: src/modules/catalog/types.ts, src/modules/catalog/repository.ts, src/app/pos/PosTerminal.tsx, src/app/qr/[storeSlug]/[tableId]/QrOrderingApp.tsx, tests/unit/ui-regressions.test.ts

  • ตรวจว่า imageUrl ถูก map จาก DB ครบทุก public/private repository.
  • เพิ่ม image slot ใน POS tile: fixed aspect ratio, lazy loading, meaningful alt text.
  • เพิ่ม placeholder แบบไม่ใช้ decorative blob; ใช้ product initials/category color.
  • ตรวจ mobile 375px: tile ไม่ overflow, button tap target อย่างน้อย 44px.

Package V2-D: POS Income Linkage

Goal: POS payment เชื่อม accounting/cashflow แบบ reliable และ traceable.

Files: src/modules/pos/order-repository.ts, src/modules/accounting/repository.ts, src/app/pos/actions.ts, src/app/(dashboard)/accounting/AccountingManager.tsx, tests/unit/accounting-pos-link.test.ts

  • กำหนด contract: paid order ต้องมี order_id ใน transaction และ cash ledger entry.
  • ถ้า transaction POS-linked ห้ามลบตรงจากบัญชี; ต้อง void/refund จาก POS เท่านั้น.
  • เพิ่ม report filter ให้เห็นรายรับจาก POS แยกจาก manual income.
  • เพิ่ม tests กัน duplicate income เมื่อ retry payment action.
