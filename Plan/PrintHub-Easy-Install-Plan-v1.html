ทำให้ติดตั้ง/ใช้งาน Print Hub ง่ายขึ้นสำหรับผู้ใช้ทั่วไป

2026-06-30 · ผู้ใช้เลือกครบทุกข้อ → แบ่ง 3 เฟส ทำเฟส 1 ก่อน (ผลมากสุด เสี่ยงน้อยสุด)

ปัญหาเดิม (จุดที่ผู้ใช้ติด)

  1. ต้องติดตั้ง Node.js แยกเอง
  2. ต้องเปิด PowerShell แบบ Admin + วางคำสั่งยาวพร้อมพารามิเตอร์ 3 ตัว
  3. ต้องคัดลอกโทเค็น/StoreId ไปมาเอง
  4. ต้องขุดหาเลขพอร์ต COM ของเครื่องพิมพ์ Bluetooth เอง

เฟส 1 — ทำตอนนี้ (ลดเหลือ "ดาวน์โหลด → ดับเบิลคลิก")

สิ่งที่ทำไฟล์แก้ปัญหา
ปุ่ม "ดาวน์โหลด config สำเร็จรูป (.json)" ในหน้า Print Hub (สร้างจากโทเค็นที่เพิ่งสร้าง ฝั่ง client ด้วย Blob)PrintHubManager.tsx#3 ไม่ต้องคัดลอกโทเค็น
ตัวติดตั้งดับเบิลคลิก: ดึง config จาก Downloads อัตโนมัติ → เช็ค Node → ถ้าไม่มีลง winget ให้ → เรียก PS installer (ไม่ต้องส่งพารามิเตอร์)ใหม่: install.cmd#1 #2
PS installer: ทำพารามิเตอร์เป็น optional → อ่านจาก config.json ที่วางไว้แทนinstall-windows.ps1#2
ตัวตรวจหาเครื่องพิมพ์: ลิสต์ COM ports + ชื่ออุปกรณ์ใหม่: find-bluetooth-ports.cmd#4
เพิ่มไฟล์ใหม่เข้า zip + ตั้ง UTF-8 flag; ปรับ README + ข้อความหน้าเว็บbuild-print-hub-zip.mjs, README-TH.txtรวม

หมายเหตุ: ไฟล์ .cmd ใช้ข้อความคอนโซลภาษาอังกฤษสั้น ๆ (ASCII) เพื่อเลี่ยงปัญหา encoding ใน cmd.exe; คำอธิบายภาษาไทยอยู่ในหน้าเว็บ + README. winget auto-install Node ครอบคลุมผู้ใช้ส่วนใหญ่บน Win10/11 โดยไม่ต้องสร้าง .exe ใหญ่

เฟส 2 — ถัดไป (วิซาร์ดในหน้าเว็บ)

ปรับ /settings/print-hub เป็นขั้นตอน 1-2-3-4 มีภาพ/ไอคอนประกอบ (ใช้ SVG/diagram แทนสกรีนช็อตจริงที่สร้างไม่ได้) และรวมการตั้งค่าเครื่องพิมพ์ทั้ง IP/WiFi และ Bluetooth ไว้ในที่เดียว ("เพิ่มเครื่องพิมพ์" แบบเลือกชนิด)

เฟส 3 — ภายหลัง/ออปชัน (รวม Node เป็น .exe)

แพ็ก agent + Node เป็นไฟล์เดียวด้วย pkg/nexe (~50MB) เพื่อไม่ต้องมี Node เลย. งานหนัก + เสี่ยง AV false-positive + ต้องเซ็นโค้ด + ทดสอบบน Windows จริง. เฟส 1 (winget auto-install) ลดความเจ็บปวดข้อนี้ไปแล้วเป็นส่วนใหญ่ จึงเลื่อนเป็นออปชัน
