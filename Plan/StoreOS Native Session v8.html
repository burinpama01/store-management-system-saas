Native session v0.1.6

ขอบเขตที่ผู้ใช้อนุญาต: React Native เดิม ต่อ session และแสดง error เชื่อมต่อ ใช้ rg แทน SocratiCode ที่ transport ปิด

  1. ต่ออายุ token ก่อน API รวม refresh ที่มาพร้อมกัน ตรวจ user เดิมและบันทึก SecureStore ก่อนเรียกข้อมูลร้าน
  2. ป้องกัน refresh เขียน session กลับหลัง logout ด้วย generation และลำดับ writes
  3. HTML/SSO/404 แสดง error ที่อ่านรู้เรื่อง โดยไม่แสดงเนื้อหาหรือข้อมูลลับ
  4. ไม่ retry คำขอ checkout อัตโนมัติ และไม่ล้างบิลเมื่อผลไม่แน่นอน
  5. ผ่าน 38 tests, TypeScript, iOS export 662 modules และ code_reviewer รวมกรณี logout ขณะ SecureStore เขียนอยู่
