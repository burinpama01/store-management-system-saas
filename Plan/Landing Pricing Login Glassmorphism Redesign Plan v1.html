Landing

Hero full-bleed มี 3D scene ของ POS, QR, receipt, stock และ report อยู่เป็น product signal แรก

  • StoreOS เป็น headline หลัก ไม่ซ่อนใน nav
  • CTA เดิม: สมัครใช้งาน, ดูแพ็กเกจและราคา
  • Section ต่อเนื่องเป็น workflow rail แทน card grid ซ้ำ

Pricing

Pricing matrix ใช้ glass card และรักษา business copy ของ Premium free trial

  • Premium: 0 บาท / 30 วันแรก
  • หลังใช้โปรแล้วแสดงราคาเดิม
  • Note โปรใช้ได้ 1 ครั้งต่อบัญชีต้องอยู่ครบ

Login

Split screen เดิม แต่ฝั่ง brand เป็น immersive 3D/glass scene และ form ใช้ glass panel

  • ไม่เปลี่ยน field, server action, invite hash flow
  • คง อีเมล, รหัสผ่าน, เข้าสู่ระบบ, ลืมรหัสผ่าน
  • ไม่แสดงคำ technical/internal ให้ user

Implementation Plan

  • เพิ่ม shared marketing components: MarketingShell, StoreOsScene3D
  • เพิ่ม CSS utilities สำหรับ marketing-page, marketing-glass, animation และ responsive states
  • ใช้ Three.js ผ่าน client canvas component พร้อม cleanup และ prefers-reduced-motion
  • ปรับ /, /pricing, /login ให้ใช้ visual system เดียวกัน
  • เพิ่ม/รัน regression tests, typecheck, lint, build และ visual smoke เท่าที่ tooling พร้อม
