แก้ปัญหาปิด LINE แล้วระบบยังส่ง

ปัญหาที่พิสูจน์แล้ว

Checkbox เดิมเปลี่ยนเฉพาะ DOM และต้องกด “บันทึก” แยก ขณะที่ runtime ถือว่า event ที่ไม่มีแถวตั้งค่าเป็นเปิดโดยปริยาย

ทางเลือก

1. Auto-save ทันที — เลือกใช้

ลดความคลุมเครือที่สุด ใช้ server action เดิม เพิ่ม pending/error และ rollback เมื่อบันทึกล้มเหลว

2. เก็บปุ่มบันทึก

เปลี่ยนข้อความเป็น “มีการเปลี่ยนแปลงที่ยังไม่บันทึก” ความเสี่ยงผู้ใช้ลืมกดยังอยู่

3. สวิตช์ LINE รวม

ต้องเพิ่ม data model และ semantics ใหม่ เกินขอบเขต bugfix ครั้งนี้

Acceptance criteria

  • สลับ checkbox แล้ว submit server action ทันทีโดยไม่ต้องกดปุ่มแยก
  • ระหว่างบันทึก control ถูก disable และมีข้อความสถานะ
  • เมื่อบันทึกล้มเหลว UI คืนค่าจาก server และแสดง error
  • เมื่อ LINE setting เป็น enabled=false ห้ามเรียก LINE provider
  • ไม่เปลี่ยน schema, provider token, account-link หรือ production environment
