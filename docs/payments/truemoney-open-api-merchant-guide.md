# คู่มือร้าน: เชื่อม TrueMoney รับเงินเข้าบัญชีตัวเอง (StoreOS)

เอกสารนี้เป็นต้นฉบับที่หน้า **ตั้งค่า → ชำระเงินลูกค้า** แสดงเป็นแผงช่วยเหลือแบบขยาย/ย่อ

## 1) ภาพรวม BYO

- ลูกค้าจ่ายแล้วเงินเข้าวอลเล็ต/บัญชีร้านโดยตรง StoreOS **ไม่ถือเงินแทน**
- ต่างจากหน้าแพ็กเกจ (ค่าสมาชิก StoreOS / Stripe) โดยสิ้นเชิง

## 2) โหมด Manual (Shop QR) vs Open API

| | Manual / Shop QR | Open API |
|---|---|---|
| เมื่อไหร่ | ใช้ได้ทันที | หลังมีสิทธิ์ในแอป TrueMoney |
| การยืนยัน | พนักงานเช็คสลิปแล้วกดยืนยัน | webhook จากแอป (อัตโนมัติเมื่อตั้งครบ) |
| ป้ายใน UI | ไม่ใช่ “เชื่อม API” | แยกแผง Open API ชัดเจน |

## 3) เงื่อนไขเปิด Open API

- โดยทั่วไป: รับโอน/เติมเข้าบัญชี TrueMoney **>~50 ครั้ง/เดือน** (นับรายการ ไม่ใช่บาท)
- โอนจากแอปธนาคารมักนับ; การกดยืนยันใน StoreOS **ไม่นับ** เป็นเงื่อนไขของแอป
- บางแหล่งเคยกล่าว 100 ครั้ง — **ยึดข้อความในแอป TrueMoney เป็นหลัก**

## 4) หา Webhook / Secret

1. เปิดแอป TrueMoney  
2. บริการ Webhook และ API ของทรูมันนี่ (ทางลัดที่รู้จัก: https://tmn.app.link/PFCCLT)  
3. รับการแจ้งเตือนรับเงิน/เติมเงิน → ได้ **Secret**  
4. **ไม่ใช่ PIN 6 หลัก**

## 5) เอา URL จาก StoreOS ไปใส่ตรงไหน

คัดลอก Webhook URL จากแผง TrueMoney Open API ใน StoreOS  
(เช่น `https://<โดเมน>/api/payments/webhooks/truemoney?storeId=…`)  
ไปวางในช่อง URL ในแอป TrueMoney

> `storeId` ใน query เป็นตัวระบุร้านชั่วคราวจนกว่าเอกสารทางการจะระบุวิธีจับคู่ร้าน

## 6) ใส่ Secret ใน StoreOS

แผง **TrueMoney Open API** → ช่อง Webhook Secret → ทดสอบเชื่อมต่อ → บันทึก → เปิดใช้เมื่อพร้อม

## 7) หลังเชื่อมต่อ — ใช้ที่ POS

Manual ยังใช้คู่กันได้สำหรับเคสสลิป; Open API ช่วยกระทบยอดเมื่อ webhook เข้า  
อย่าแสดง Manual ว่า “API connected”

## 8) ความปลอดภัย

- ห้ามแชร์ Secret  
- URL ในแอปอาจมีอายุ — อัปเดตเมื่อหมดอายุ  
- หมุน Secret ทันทีถ้าสงสัยว่าหลุด

## 9) แก้ปัญหาเบื้องต้น

- ยังเลือกเมนู webhook ในแอปไม่ได้ → ยังไม่ครบเงื่อนไขสิทธิ์  
- ทดสอบผ่านแต่ไม่ auto-paid → ตรวจยอด/pending order และว่าเปิดใช้ Open API แล้ว  
- Stripe / ค่าสมาชิก ไม่เกี่ยว

---

**หมายเหตุทางเทคนิค:** รูปแบบ JWT/webhook แบบชุมชน (`{ "message": "<JWT>" }` HS256) เป็นค่าชั่วคราว — ต้องยืนยันจากคู่มือในแอปเมื่อมีสิทธิ์ ห้ามประดิษฐ์ endpoint สร้างรายการชำระที่ไม่มีในเอกสารทางการ
