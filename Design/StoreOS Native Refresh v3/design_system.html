ขอบเขตที่ปรับ

หน้าโหลดและเข้าสู่ระบบ หน้าแรก หน้าขาย ตะกร้าและชำระเงิน บิล เดลิเวอรี เครื่องพิมพ์ และการตั้งค่า ใช้สี ระยะห่าง ปุ่ม และสถานะโหลด/ว่าง/ผิดพลาดชุดเดียวกัน

iPhone: หน้าหลักคอลัมน์เดียว เมนูด้านล่าง ตะกร้าเป็นแผงเลื่อนที่มีปุ่มชำระเงินเข้าถึงได้ แป้นพิมพ์ไม่บังช่องหรือปุ่ม ไม่ให้ dialog ล้นขอบจอ

iPad: แยกพื้นที่สินค้าและตะกร้าเมื่อพื้นที่เพียงพอ รองรับแนวตั้ง/แนวนอนและ safe area

แนวทางที่เทียบ

1. แนะนำ: ธีมเว็บ + layout native สำหรับมือถือ — สอดคล้องแบรนด์และใช้งานสะดวก

2. เปลี่ยนสีอย่างเดียว — เร็ว แต่ยังเหลือปัญหาหน้าจอเล็ก

3. ออกแบบธีมใหม่ทั้งหมด — ใช้เวลามากและแตกต่างจากเว็บ

การยืนยันผล

ตรวจ 375/390/430 px, iPad แนวตั้ง/แนวนอน, keyboard, ตัวหนังสือขยาย, รายการยาว และตะกร้า พร้อมเทสต์ API เดิมและ reviewer ก่อน build; ผลเครื่องจริงแยกจากผลจำลอง
