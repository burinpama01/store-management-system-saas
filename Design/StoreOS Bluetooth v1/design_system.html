เชื่อมต่อแล้ว กรุณาพิมพ์ทดสอบ

พฤติกรรมที่กำหนด

  1. ผู้ใช้กดค้นหาเอง ขอสิทธิ์ Bluetooth และค้นหา 12 วินาที
  2. เลือกเครื่อง แล้วตรวจ service/characteristic ช่อง UART ที่รู้จัก ไม่ส่งข้อมูลไปทุกช่องที่เขียนได้
  3. พิมพ์ภาพภาษาไทย 384 จุด ส่งทีละ 20 bytes ไม่ตัดกระดาษสำหรับเครื่องตัดมือ
  4. เมื่อส่งไม่ครบ แสดงไม่ทราบผลและให้ตรวจเครื่องก่อนส่งซ้ำ ไม่มี retry อัตโนมัติ
  5. เมื่อออกจากหน้า ปิด scan/connection ไม่เริ่มพิมพ์เองตอนกลับเข้าแอป

ขอบเขตและขั้นต่อไป

v0.4.0 เพิ่ม BLE และเอกสารทดสอบ ยังไม่มีใบเสร็จจริงผ่าน Bluetooth และยังไม่ยืนยัน protocol ของสองรุ่น

ลำดับ: Codemagic native compile → TestFlight scan/GATT/Thai paper → canonical receipt API → พิมพ์ใบเสร็จ POS → POS parity → โมดูลเว็บอื่น

BLE library ไม่ใช่ตัวเชื่อม Bluetooth Classic หาก scan ไม่พบ ต้องใช้ผลจากเครื่องจริงหรือเอกสารผู้ผลิตเลือกช่องทางที่ตรงรุ่น
