หลักการ

ใช้ native checkbox เพื่อ accessibility, target อย่างน้อย 44px, ไม่ใช้สีเป็นสัญญาณเพียงอย่างเดียว และสถานะ server ต้องมีข้อความกำกับเสมอ

State contract

พร้อมส่ง

Server ยืนยัน enabled และ provider พร้อม

ปิดไว้

Server ยืนยัน enabled=false

กำลังบันทึก…

Disable control และตั้ง aria-busy

บันทึกไม่สำเร็จ

Rollback ค่าและเปิด dialog error

Interaction rules

  • onChange อัปเดตค่า optimistic แล้วเรียก requestSubmit()
  • Success ใช้ inline feedback “บันทึกแล้ว” ไม่เปิด modal รบกวนทุกครั้ง
  • Error ใช้ dialog เดิมเพื่อให้เห็นชัดและคืน checkbox เป็นค่า server
  • คง token สีและ spacing ของหน้า Settings เดิม ไม่เพิ่ม dependency
