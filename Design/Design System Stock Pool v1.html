Validation และ Accessibility

จำนวนห้ามว่าง
กรุณากรอกจำนวนเต็มตั้งแต่ 0 ขึ้นไป ระบบจะไม่แปลงช่องว่างเป็นศูนย์
  • ปุ่มและ field สูงอย่างน้อย 44px
  • Dialog trap focus, ปิดด้วย Escape ได้เมื่อไม่มีข้อมูลที่ยังไม่บันทึก และคืน focus ให้ปุ่มเดิม
  • ไม่ใช้สีอย่างเดียว: แสดงข้อความ “หมด”, “ใกล้หมด”, “เพียงพอ” คู่กับสี
  • บนมือถือ operation selector และ action button เรียงแนวตั้ง
