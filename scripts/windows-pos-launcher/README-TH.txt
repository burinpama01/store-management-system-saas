StoreOS POS - โปรแกรมขายหน้าร้านสำหรับ Windows (พิมพ์ตรงเข้าเครื่องพิมพ์ IP)

ติดตั้ง
  1. แตกไฟล์ zip
  2. ดับเบิลคลิก install.cmd (ไม่ต้องใช้สิทธิ์ Administrator)
  3. โปรแกรมเปิดเอง -> ล็อกอินด้วยบัญชี StoreOS
  4. แท็บ "เครื่องพิมพ์" -> ตั้ง IP เครื่องพิมพ์
     (ปุ่ม "ประวัติการพิมพ์ / ค้นหาเครื่องพิมพ์" ช่วยหา IP ในวง WiFi)

ใช้งาน
  - มีแท็บ "ขาย (POS)" / "เมนูสินค้า" / "เครื่องพิมพ์" - หน้าอื่นจะเปิดในเบราว์เซอร์แทน
  - ใบเสร็จพิมพ์ตรงจากเครื่องนี้เข้าเครื่องพิมพ์ ไม่ผ่านอินเทอร์เน็ต
  - ไฟสถานะมุมขวาบนบอกว่าเครื่องพิมพ์พร้อมไหม
  - ต้องเปิดโปรแกรมไว้ตลอดเวลาร้านเปิด (ออร์เดอร์ QR พิมพ์อัตโนมัติเมื่อโปรแกรมเปิดอยู่)

log ของโปรแกรม: %LOCALAPPDATA%\StoreOS\PosLauncher\logs
ถอนการติดตั้ง: คลิกขวา uninstall-pos-launcher.ps1 -> Run with PowerShell
